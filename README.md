# 🌐 CCNA Networking Labs
# Welcome to my CCNA Networking Labs repository.

This repository contains my hands-on networking practice using Cisco Packet Tracer. I am building these labs step-by-step to strengthen my understanding of CCNA concepts, network configuration, troubleshooting, and practical networking skills.

# 🎯 Objectives

The main objectives of this repository are:

Learn networking from basic to advanced concepts
Practice Cisco IOS commands
Build and configure network topologies
Understand IPv4 addressing and subnetting
Configure VLANs and trunking
Practice inter-VLAN routing
Configure DHCP
Practice static routing and dynamic routing
Develop network troubleshooting skills
Maintain a practical CCNA portfolio on GitHub

Trunking
Inter-VLAN Routing

OSPF
Routing & Switching
